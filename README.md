# 🎮 Roblox Luau Learning

A beginner-friendly repository documenting my journey of learning **Luau scripting** and **Roblox game development** through practical coding, experiments, and projects.

---

## 📌 About

**Luau** is the scripting language used by Roblox to create game logic, gameplay mechanics, interactive systems, and more.

This repository starts with the fundamentals of Luau and gradually progresses toward **Roblox-specific scripting and complete game development**.

The main goal is to learn by **writing code, experimenting, and building projects** rather than only following tutorials.
